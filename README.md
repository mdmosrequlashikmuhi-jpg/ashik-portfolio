# Mosrequl Ashik Muhi — Personal Marketing Portfolio

Responsive dark-blue personal portfolio built with HTML, CSS and JavaScript. Ready for GitHub Pages.

## Add your portrait
Put your photo in the `assets` folder and name it exactly `profile.jpg`. The image path is `assets/profile.jpg`.

## Personalize before publishing
- In `index.html`, replace `your-email@example.com` with your email address.
- Replace the `#` social links with your Facebook, LinkedIn and Instagram profile URLs.
- Edit the About, Skills and Services text to match your actual experience.
- Replace the sample project cards with screenshots and details of your real work.
- The skills and project examples are placeholders, not claims of verified experience.

## Publish with GitHub Pages
1. Create a **Public** repository, for example `ashik-portfolio`.
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub to display the published URL, usually `https://YOUR-USERNAME.github.io/ashik-portfolio/`.

No build step, PHP, WordPress or database is required.
